# Car Racing Game

A simple car racing game built with Pygame.

## Prerequisites

- Python 3
- Pygame

## Installation

Install the required dependencies:

```bash
pip install pygame
```

## How to Play

Run the game:

```bash
python3 game.py
```

- Use the **Left** and **Right** arrow keys to move your car.
- Avoid the red enemy cars!

## Notes

If the `car.png` and `enemy_car.png` assets are missing, the game will use colored rectangles as placeholders (Blue for your car, Red for enemy cars).
