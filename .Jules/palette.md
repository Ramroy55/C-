## 2025-02-15 - Headless Game Asset Fallback and Game Loop Break
**Learning:** In headless game environments (like automated CI/CD pipelines testing Pygame), graphical assets (like .png sprites) might be missing, and standard display servers are absent. Designing a robust UX requires catching both `pygame.error` and `FileNotFoundError` during image loading and immediately falling back to semantic vector/colored shape rendering. Additionally, breaking the main game loop immediately after triggering the game over screen prevents display surface crashes during execution teardown.
**Action:** Always wrap image loading in robust try-except blocks and render clean colored rectangles as fallback sprites using existing dimension constants. Break the main loop instantly upon game-over triggers to ensure clean exit sequences.
