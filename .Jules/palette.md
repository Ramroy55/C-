## 2025-07-20 - Game Asset Fallback and Visual Polish in Pygame
**Learning:** Pygame applications are prone to crash on launch if visual assets (such as PNG images) are missing or fail to load. This creates a brittle user experience and prevents standard automated verification. Implementing a robust asset fallback pattern that catches loading exceptions and defaults to rendering colored rectangles of identical dimensions (e.g., BLUE for player, RED for enemy) guarantees that the game remains fully playable and visually intuitive under all circumstances. Additionally, centering display text precisely via `text.get_rect(center=(x, y))` prevents visual overlapping and maintains layout consistency.
**Action:** Always implement try-except blocks for asset loading in Pygame and design semantic fallback visual elements. Center text objects dynamically rather than using hardcoded pixel coordinates to ensure the UI scale remains elegant.
