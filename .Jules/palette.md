## 2025-07-25 - Robust Asset Fallbacks and Safe Game Terminations in Headless Pygame
**Learning:** Pygame environments (especially headless CI/CD pipelines) frequently lack local image assets or graphical displays, leading to uncaught initialization crashes. Implementing a graceful fallback that renders basic shapes when assets are missing prevents runtime crashes and ensures continuous playability. Additionally, immediately breaking the main game loop before executing `game_over` sequences prevents rendering errors (e.g., display Surface quit) during shutdown.
**Action:** Use nested exception handling (catching both `FileNotFoundError` and `pygame.error`) to load images, and gracefully fallback to drawing standard shapes (like colored rectangles) using standard constants and predefined dimensions. Ensure exit logic explicitly breaks out of active game loops and cleanly shuts down the Pygame subsystem.
