## 2025-07-24 - Pygame Headless Verification and Robust Fallbacks
**Learning:** Verified Pygame-based UIs in a headless environment by relying on image load fallbacks to handle missing assets (e.g. car.png, enemy_car.png) gracefully using standard colors and dimensions, and preventing display surface rendering crashes on loop exit by explicitly breaking out of the game loop upon collision.
**Action:** When working on Pygame micro-UX improvements in environments that could run headlessly or with missing files, always wrap image loading in a try-except block handling `pygame.error` and `FileNotFoundError`, provide explicit colored rectangle drawing routines using defined dimensions, pre-initialize font systems once outside the game loop, and explicitly break out of the main loop upon a fatal collision before quitting Pygame.
