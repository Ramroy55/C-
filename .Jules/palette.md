## 2025-02-15 - Pygame Text Centering and Asset Fallback Robustness
**Learning:** In Pygame-based applications, hardcoded text positions can cause misalignments across different screens and font sizes, creating a disjointed user experience. Utilizing `text.get_rect(center=(x, y))` ensures mathematically precise text centering. Additionally, catching both `pygame.error` and `FileNotFoundError` during asset loads is critical to prevent crashes, allowing smooth visual fallbacks like drawn rects with standard color palettes (such as `BLUE` for player, `RED` for enemy).
**Action:** When working on Pygame or similar canvas-based interfaces, always initialize fonts once globally, dynamically center text elements with bounding box calculations, and provide styled colored primitive fallbacks to guarantee uninterrupted gameplay.
