## 2024-08-09 - Pygame Graceful Image Fallback and Center Text Alignment
**Learning:** In Pygame, when image assets are missing, catching FileNotFoundError and pygame.error is critical to prevent immediate game crashes, allowing the use of shape-based fallbacks using designated game dimensions and cohesive theme colors. Furthermore, centering Game Over elements via get_rect(center=(x, y)) dramatically improves player experience by avoiding hardcoded offsets across different screens.
**Action:** Always wrap pygame image loading in try-except blocks catching both pygame.error and FileNotFoundError, utilize standard color constants and existing dimensions for default rectangle fallbacks, and always center game texts dynamically rather than using static hardcoded coordinates.
