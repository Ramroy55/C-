## 2025-07-21 - Pygame Fallbacks and Scoring Feedback
**Learning:** In Pygame-based desktop/arcade games, missing assets (such as images/sprites) can cause immediate startup failures. Implementing a robust asset fallback strategy using standard colors and bounding shapes ensures the game remains fully playable even if assets are missing. Additionally, a clear scoring indicator and a polished Game Over screen provide necessary visual feedback, supporting player engagement and accessibility.
**Action:** Always wrap `pygame.image.load` in try-except blocks that catch both `pygame.error` and `FileNotFoundError`. If loading fails, fallback to rendering colored rectangles matching standard color schemes. Support this with clear on-screen textual feedback (e.g., scores, status) using standard, centered fonts to preserve the user's micro-UX flow.
