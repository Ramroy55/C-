## 2025-02-15 - Enhancing Immediate Player Feedback & Robust Pygame Asset Fallbacks
**Learning:** Pygame environments can easily fail to run if static image assets are missing or cannot be loaded correctly. In these scenarios, catching both FileNotFoundError and pygame.error allows for robust fallback options, such as rendering standard color-coded rectangles representing the target assets without using magic numbers. Additionally, visual micro-UX patterns (like centered Game Over text, live gameplay score counters, and showing final results) significantly improve immediate players' feedback loops.
**Action:** Always wrap Pygame resource loading (images, fonts, audio) in try-except blocks, use defined dimensions instead of hardcoded numbers, use text.get_rect(center=(...)) to perfectly align UI text components on screen, and initialize font objects outside the main game loop to optimize performance.
