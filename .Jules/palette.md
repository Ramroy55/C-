## 2025-08-13 - Robust Pygame Fallbacks and Precise Text Centering
**Learning:** In Pygame game design, especially within resource-constrained or headless environments, failing to load image assets gracefully breaks the entire user experience. Implementing a solid fallback system with basic geometric shapes colored with high-contrast, recognizable standard UI colors (BLUE for player, RED for enemy) mapped to standard collision boundaries ensures that the game remains fully playable. Furthermore, aligning and positioning text components dynamically using `get_rect(center=(x, y))` prevents visual overlap and truncation issues across screens.
**Action:** Always wrap asset loading in try-except blocks handling `pygame.error` and `FileNotFoundError`, and implement geometric vector fallbacks. Initialize fonts once outside the main execution loop for performance, and center text via rect bounding boxes.
