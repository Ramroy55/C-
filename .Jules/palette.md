## 2025-07-19 - Robust Image Asset Fallback and Score Retention in Pygame
**Learning:** Headless gaming environments lack assets (`car.png`, `enemy_car.png`), causing standard execution crashes. Relying strictly on a success-only loading path degrades robustness. Graceful fallbacks using standard geometric primitives (colored rectangles mapped to correct object dimensions) prevent crashes while retaining exact collision boundaries. Additionally, immediate scoring/progression feedback on screen and a cleanly terminated, centered game-over display significantly elevate player motivation and UI clarity.
**Action:** When designing Pygame or canvas-based interactive structures, always wrap asset loads in dual `pygame.error`/`FileNotFoundError` handler catch blocks, fallback to standard colored rects using exact dynamic dimension variables, and employ text.get_rect(center=(...)) to ensure visual alignment regardless of text width.
