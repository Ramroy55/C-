## 2025-02-13 - Centered HUD and Headless Visual Verification in Pygame UIs
**Learning:** For terminal-based or headless gaming environments, verifying UI and rendering quality is challenging. By leveraging Pygame's dummy video driver `SDL_VIDEODRIVER=dummy` and using `pygame.image.save()` programmatically, we can generate frame buffers that are verifiable with image viewers without needing a display server. Furthermore, standard UI elements in Pygame should always be dynamically centered using `text.get_rect(center=(x, y))` instead of hardcoded magic offset coordinates to keep the layout clean, accessible, and responsive across varying screen resolutions.
**Action:** Always verify Pygame-based changes by running programmatically with a dummy driver, capturing temporary visual artifacts for validation, and centering texts precisely with `get_rect(center=...)` before shipping.
