## 2024-07-23 - Robust Headless Fallbacks and Center Formatting in Pygame
**Learning:** Headless environments (like CI/CD or docker containers) cannot load raw Pygame graphical windows or audio without dummy drivers, and missing local assets (like `car.png`) will crash the application immediately if not handled gracefully. Implementing a robust try-except fallback to standard color rectangles using defined game dimensions prevents application crashes and maintains high-quality micro-UX. Centering game over texts and scores using Pygame's `get_rect(center=...)` ensures a balanced, professional look.
**Action:** Always catch `pygame.error` and `FileNotFoundError` during asset loading and fallback to standard colors (Blue for player, Red for enemy) with defined dimension variables. Center text with `get_rect(center=...)` and cache font instances outside the main game loop for performance.
