## 2025-07-27 - Graceful Asset Degradation & Headless Game Loop UX
**Learning:** In Pygame environments, missing image files can easily crash the whole application, ruining user UX completely. Graceful degradation via try-except blocks that fall back to standard color blocks (Blue for player, Red for enemy) keeps the game fully playable. Furthermore, to avoid headless display thread crashes, it is critical to explicitly break out of the main game loop immediately after triggering the game over sequence, and center visual typography elements properly.
**Action:** Always wrap `pygame.image.load` in multi-exception handlers (for both `FileNotFoundError` and `pygame.error`) and fall back to dynamically scaled color rectangles. Explicitly break the main loop on termination, and use `get_rect(center=(...))` to accurately position text.
